# Система управления отделом кадров (HR Department Management System)

Настольное приложение, разработанное на C# и WPF (.NET 8.0), для управления данными сотрудников, структурой отделов, историей карьеры и кадровыми событиями.

## Функционал
* **Управление сотрудниками:** Добавление, редактирование и просмотр подробных профилей и статусов сотрудников.
* **Отслеживание карьеры:** Фиксация повышений, переводов между отделами и полной истории кадровых перемещений.
* **Журнал событий и отпусков:** Учет кадровых событий, заявок на отпуск и настраиваемых типов мероприятий.
* **Отчетность и экспорт:** Формирование отчетов по численности отделов, предстоящим дням рождения и запланированным событиям (с поддержкой экспорта в Excel через OpenXml).
* **Ролевой доступ:** Система аутентификации и управления пользователями.

## Стек технологий
* **Язык:** C# (.NET 8.0)
* **Фреймворк:** WPF (Windows Presentation Foundation)
* **Библиотеки:** ClosedXML, DocumentFormat.OpenXml
